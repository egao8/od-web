EGAlpha website pivoted from flashy fintech startup to institutional quant desk identity. Core philosophy: "understated competence."

**Why:** The previous site looked like a retail algo platform selling bots. The target audience is developers, quant enthusiasts, technically literate traders, sophisticated retail, and eventually allocators. Credibility requires restraint.

**How to apply:**
- Site is 4 pages: Home, Strategies, Research, Contact. No performance data shown publicly (industry standard — no quant firm shows returns).
- Design: monochrome grey tiers (foreground → text-secondary → text-tertiary → text-quaternary), Lora serif for headings, Inter for body, zero border-radius, no flashy effects.
- Contact is just an email (inquiries@egalpha.com), no forms. Matches Voleon/Headlands approach.
- Tone: matter-of-fact, no marketing language, no "AI-powered" buzzwords, no luxury imagery.
- Reference firms: Voleon (ultra-minimal), Headlands, Radix Trading, Jane Street, Two Sigma.
- Infrastructure details are folded into "What we do" paragraph, not a separate page.
- Strategy families (EG-MR, EG-LIQ, EG-RV, EG-VOL, EG-MOM, EG-EXE) described abstractly on Strategies page.

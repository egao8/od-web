Performance Presentation Standards

This section is extremely important.

Should Performance Be Public?

Industry answer:

Yes — partially.

Sophisticated users EXPECT some evidence.

However:

full transparency is uncommon,
raw logs are usually private,
and allocators typically request deeper information later.

Recommended approach:

Publicly Show
equity curve,
drawdown profile,
Sharpe,
volatility,
holding period profile,
deployment duration,
live vs simulated alignment,
selected risk metrics.
Available Upon Request
broker statements,
detailed logs,
monthly returns,
execution analytics,
deeper validation studies.

This mirrors many boutique quantitative operations.

Important Performance Rules
Never:
overstate results,
hide drawdowns,
imply guaranteed returns,
cherry-pick windows,
present unrealistic compounding.
Always:
include disclaimers,
discuss risk honestly,
mention execution assumptions,
distinguish live vs simulated data.

Transparency creates credibility.
